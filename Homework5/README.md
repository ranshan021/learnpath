## 在这里编写你的阅读笔记
（阅读笔记不要求字数，但是需要自己写，AI生成的一律打回）
   1. 模板中你之前不了解的c/c++功能（如函数指针，class类等）
      struct是打包的一系列变量，class可以看作一系列变量的基础上加入了成员函数。
      在CAN_bsp.c中，typedef定义一个函数类型，将其作为一个函数的模板传入类中，要使用具体的类时，传入具体的函数，使这个函数与这个类绑定，之后类调用这个函数时，就是调用传入的这个具体函数。
      成员函数对于一个类的所有对象都是相同的，但是使用函数指针就可以让一个类的所有对象调用同一类型的不同函数。
      在读取滤波器匹配的ID时，是用index在表can_device_rx_list中查找对应的接收对象，进行相应的处理。这个表里面存的是对象的指针。
   2. 模板中关于FreeRTOS的使用
      can发送使用队列和计数信号量，可以有效防止因为邮箱满了而丢帧（此队列最多存16帧）
   3. 相比自己电机任务/整车调试中的代码，这份模板相对于你的代码有什么优点
      优雅，如果想要配置新的接收和发送任务很方便，CAN通信阻塞的风险更小
   4. 如何使用这个模板
      注意处理C和C++的混编，要使用CAN_bsp只能在C++文件里面include，然后在相应的头文件里提供C的接口函数
      发送：定义全局数据缓冲区，创建发送对象:can_device_transmit motor_tx(...)，再调用:motor_tx.can_send_msg()
      接收：写回调解析函数，中断回调会自己调用
